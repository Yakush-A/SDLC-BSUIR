## Оформление

Диаграммы оформлены в монохромном стиле, близком к примерам из задания на лабораторную работу №5:

- белый фон, чёрные линии и текст, без теней и цветовых заливок;
- стандартная нотация UML 2.x (`skinparam style strictuml`);
- шрифт DejaVu Sans;
- у актёров, прецедентов, состояний, дорожек и участников белая заливка и чёрная рамка;
- «человечками» показаны только люди (Игрок, Разработчик, Оператор), а внешние системы (Typst Renderer, хост портрета) — прямоугольниками со стереотипом `<<system>>`;
- связи на диаграммах вариантов использования, активности и последовательности ортогональные (`skinparam linetype ortho`); на диаграммах состояний переходы кривые, как в примере задания, а названия состояний даны на английском с русским пояснением в скобках.

Общий стиль задаётся блоком `skinparam` в начале каждого `.puml`, поэтому диаграммы можно перерисовать без изменения содержания.

## Перерисовка PNG

Требуется Java 17+ и [PlantUML](https://plantuml.com/):

```bash
cd uml/diagrams
java -DPLANTUML_LIMIT_SIZE=16384 -jar plantuml.jar -tpng -scale 2 *.puml
```

PNG создаются рядом с исходниками. Имя файла PNG определяется строкой `@startuml <name>`, поэтому оно совпадает с именем `.puml`.
