# Глоссарий проекта

Модуль «Генератор отчётов листов персонажей» (Sheet Export) для Live D&D List

Версия 0.1, 15.11.2026, автор А.П. Якуш

Источники: SRS v0.2 (`../srs/srs.md`), SDD v0.4 (`../sdd/sdd.md`), ADR-0001 … ADR-0007 (`../sdd/`). Термины упорядочены по алфавиту внутри групп.

## 1. Предметная область

| Термин | Определение | Синонимы / английский вариант | Источник |
|--------|-------------|-------------------------------|----------|
| D&D 5e | Dungeons & Dragons, пятая редакция: настольная ролевая игра; в проекте используется набор правил SRD 2014 | Dungeons & Dragons 5th Edition | SRS 1.3 |
| Игровая система | Набор правил настольной ролевой игры со своей структурой листа персонажа (D&D 5e, в будущем другие) | Game system | SRS BO-3 |
| Игрок | Пользователь приложения, владелец листа персонажа; запускает экспорт | Player | SRS 2.4 |
| Лист персонажа | Набор данных персонажа (характеристики, навыки, бой, снаряжение, заклинания, описания) и его печатная форма | Character sheet | SRS 1.3 |
| Мастер игры | Ведущий игры; получает PDF от игрока, в приложении не работает | Game Master, DM | SRS 1.3 |
| Персонаж | Вымышленный герой игрока, данные которого хранятся в Live D&D List | Character | SRS 1.3 |
| Портрет | Изображение персонажа, заданное ссылкой `portraitUrl` | Portrait | SRS 1.3 |
| Спасбросок | Бросок кубика для избегания эффекта; в листе — бонус по каждой из шести характеристик | Saving throw | SRS REQ-FUNC-010 |
| SRD | System Reference Document: открытая часть правил D&D, из которой берутся данные о расах, классах и заклинаниях | System Reference Document | SRS AS-6 |
