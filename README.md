\# ГЕНЕРАТОР ОПРАВДАНИЙ



\## Информация о проекте:

\- Автор: Якуш Алексей Павлович

\- Группа: 450501

\- Дисциплина: Жизненный цикл разработки программного обеспечения



Проект представляет собой нативное Windows Forms приложение для генерации оправданий в зависимости от выбранной пользователем ситуации.



\### Основные функции:



\- \*\*Выбор ситуации:\*\* пользователь выбирает категорию оправдания — учеба, работа, опоздание или забывчивость.

\- \*\*Ввод данных:\*\* дополнительное диалоговое окно позволяет указать необходимые данные для формирования оправдания.

\- \*\*Генерация оправдания:\*\* формирование готового текста оправдания на основе выбранной ситуации и введенных данных.

\- \*\*Сохранение состояния:\*\* запоминание последних введенных данных и их автоматическое восстановление при повторном открытии диалога.

\- \*\*Валидация:\*\* проверка корректности введенных данных и вывод сообщений при ошибках.

\- \*\*Архитектура:\*\* реализация логики на основе паттерна MVC (Model-View-Controller).Проект представляет собой Windows Forms приложение для генерации оправданий в зависимости от выбранной пользователем ситуации.
